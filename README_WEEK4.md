# PBKK Week 4 — Blade + Vite

Implemented from the Week 2 base project according to the Week 4 assignment PDF.

## Run

```bash
composer install
npm install
npm run build
php artisan serve
```

If `.env` does not exist, copy `.env.example` to `.env`, then run `php artisan key:generate`.

Main routes:
- `/`
- `/profil-mahasiswa`
- `/ide-agent`
- `/ide-agent?mode=dark`
- `/beranda?user=Andi`
